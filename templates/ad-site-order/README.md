# Шаблон рекламы «сайт принимает заказы» (Remotion)

Код готового ролика Scent Harbor (19.11.2026), вынесенный по каркасу `reference/ad-template-site-order.md` (пункт 9). Данные ролика лежат в одном файле `config.json`, в нём сейчас выдуманный пример, им проверена сборка (ниже). Промты для двух заходов: `prompts/ad/site-order_two_pass.md`.

Сюжет и сроки тактов, сцена, проверки и критерий готовности описаны в каркасе. Этот README только про код.

## Что внутри

| Путь | Что делает |
|---|---|
| `config.json` | все переменные ролика: бизнес, заказ, тексты интерфейса, подписи, карточка, музыка, вариант движения и света, палитры со столом, точки экранов, съёмка |
| `src/` | Remotion: `scenes.ts` (камеры, такты, таймлайн), `Views.tsx` (сцены владельца и клиента), `Reel.tsx` (ролик, финал, карточка, обложка), `Flat.tsx` и `flatgeo.ts` (стол, устройства, тени, подписи, проекция), `export-boxes.ts` (рамки для проверок), `Root.tsx` (композиции) |
| `capture/capture.js` | съёмка сайта Playwright: один заказ на планшете и телефоне владельца, кадры кабинета каждые 33 мс |
| `scripts/` | `make_placeholders.py` (заглушки для проверки сборки), `table_photo.py`, `logo_alpha.py`, `music_cut.py` (отрезок трека, затухание, −14 LUFS), `build_reel.sh` (рендер по тактам и сведение), `run_checks.sh` (все проверки) |
| `checks/` | `board_check.py` (зоны, буквы событий, обрезанные слова), `caption_big.py` (крупные подписи, контраст 7:1), `final_check.py` (участки без подписи, доли, линейные кривые, обложка, формат), `variant_check.py` (захваты и сцена соответствуют варианту), `logo_check.py`, `caption_boxes.py` |

Поля подписей проверяет `tools/caption_margins.py` из корня репозитория.

| `src/states/states_tablet.json`, `states_phone.json` | рамки, тексты с высотой букв, слова | тот же `capture.js` |

| фото стола по путям палитры (`palettes.<имя>.table.full`, `.tile`, в `public/`) | матовое дерево или камень, свободная лицензия, лучше от 4000 px; для светлой палитры светлый стол | `python scripts/table_photo.py ФОТО.jpg`, затем переименовать под пути палитры |
| `public/brand/logo_alpha.png` | логотип студии, PNG с прозрачным фоном | `python scripts/logo_alpha.py ЛОГО.png` (снимает белый фон, форму и цвет не трогает) |
| файл трека из `config.json` `music.file` | MP3 или WAV, выбирает человек на слух, лицензия в CREDITS.md проекта | `python scripts/music_cut.py` пишет `public/audio/reel.wav` |

Сайт снимают в отдельной сборке для рекламы (флаг вроде `AD_CAPTURE` в репозитории сайта): без пометок «демо», кабинет владельца со своей шапкой, растянутый приход заказа (уведомление, через 0,3 с строка раскрывается сверху за 0,55 с), кнопка «принять» на новой строке, на форме нет шага оплаты. Эта сборка живёт в репозитории сайта и не выкладывается. Для вариантов она же читает два входа от `capture.js`: CSS-переменные палитры (`capture.cssVars`) и параметр страницы заказов `?adEnter=left|right|top` (`capture.enterParam`), с которой стороны въезжают уведомление и новая строка (сдвиг `transform` на самих элементах `[role=status]` и `li`, чтобы его видели рамки). Экраны в шаблоне не дорисовываются: что сайт не умеет, того в ролике нет, и `variant_check.py capture` это ловит.

## Переменные `config.json`

- `business`, `order`: название, номер заказа, сумма как на экране, имя клиента, товар.
- `labels`: тексты интерфейса как их рисует DOM после `text-transform` (уведомление, статусы, кнопка, «Итого», заголовок «Заказ №{n} оформлен»). По ним проверки находят события.
- `captions`: три подписи (хук, клиент, владелец), до двух строк, `accent` = [строка, слово] ключевой фразы, `size` 84 (заглавные около 60 px в 1080).
- `card`: строка карточки и её ключевая фраза, слово действия, контакт, логотип (`logoPx` печатает `logo_alpha.py`, `logoInkWidth` не меньше 432 = 40 % ширины).
- `cover`: заголовок обложки по строкам.
- `music`: файл, BPM, `start` (секунда трека на сильной доле), доли конца хука, касания владельца, карточки (на смену фразы трека) и конца.
- `variant`: вариант движения и света (таблица «Варианты» ниже), `cam`: числа камер, нужные этой комбинации.
- `palettes`: готовые палитры (тёмная, светлая, цветная) с одним акцентом: цвета экранов (подставляются сайту при съёмке), акцент, цвета подписей и подложки (`veil`, её плотность за подписью `halo`), фото стола (`table`: пути, размер исходника, ширина в мире, 29 = 1 см, тон `grade`, глубина затемнения к краям `shade`). Светлой палитре нужны плотная светлая подложка и слабое затемнение: иначе тёмные подписи не дают 7:1.
- `layout`: точки и рамки экранов в CSS px захватов (кнопка «принять», корзина, заголовок страницы заказа). После съёмки взять из `src/states/*.json` (`el.*`, `texts`).
- `capture`: адрес сайта, пути страниц, подписи кнопок, поля формы, ключи хранилища заказов, примерные заказы «вчера», имена CSS-переменных палитры и параметр стороны въезда.

Страны и города в подписях и на карточке не называть.

## Команды по порядку

1. Скопировать шаблон в папку проекта: `cp -r templates/ad-site-order <проект>/reel`, затем `npm install` (только `remotion`, `@remotion/cli`, `react`, `react-dom`).
2. Заполнить `config.json`. Положить шрифты, фото стола, логотип и трек (таблица выше), сделать `table_photo.py`, `logo_alpha.py`, `music_cut.py`.
3. Поднять рекламную сборку сайта, снять: `node capture/capture.js tablet` и `node capture/capture.js phone` (Playwright: `capture.playwrightModule` или переменная `PLAYWRIGHT_MODULE`). Перенести рамки из `src/states/*.json` в `config.json` `layout`.
4. Раскадровка: `npx remotion render build/bundle Board out/board --sequence` после `npx remotion bundle src/index.ts --out-dir build/bundle`. Кадры подбирают переменными окружения с приставкой `REMOTION_` (до рендера Remotion доходят только такие), не правя код: `REMOTION_HY=700`. Имена: хук `HX HY HS HP HPY HPS`, телефон клиента `K0X K0Y K0S`, наезд `K0WX K0WY K0WS`, общий план `K1X K1Y K1S`, корзина `K2X K2Y K2S`, страница заказа `K3X K3Y K3S`, наезд на «Итого» `K3BX K3BY K3BS`, касание владельца `FTX FTY FTS FTP`, строка на всю ширину `FRX FRY FRS FRP`, подписи `CAPS`, проезд `sweep` `SW0X SW0Y SW1X SW1Y SW3X SW3Y`. Цифры подбирать по `node build/export-boxes.cjs out.json` (рамки, буквы, обрезанные слова) с теми же переменными. Найденные для всех роликов записать в код по умолчанию, нужные одной комбинации варианта записать в `config.json` `variant.cam`.
5. Ролик: `sh scripts/build_reel.sh` (всё) или `BEATS="card" sh scripts/build_reel.sh` (только изменённый такт). Файл `out/reel.mp4`, для правок задавать новое имя `OUT=out/reel_v2.mp4`.
6. Проверки: `sh scripts/run_checks.sh`, лог `out/checks.log`. Если шаблон скопирован вне репозитория, `CLIP_MAKER=<путь к clip-maker-8000>`.
7. Один свежий ревьюер на готовый ролик, правки один раз (`prompts/ad/site-order_two_pass.md`).

## Варианты

Ролики по одному каркасу не должны повторять друг друга. Блок `variant` в `config.json` меняет движение, свет и цвет. Время тактов, музыка, доли, тексты подписей, карточки и обложки, их места и время от варианта не меняются, подписи остаются в экранных координатах в зоне Reels.

| Параметр | Значения | Что меняет | Проверено |
|---|---|---|---|
| `enterFrom` | `top`, `left`, `right` | откуда въезжают уведомление и новая строка в кабинете владельца; делает сайт при съёмке (`?adEnter=`), шаблон экраны не двигает | `top` (1, 3), `left` (2); `right` только на заглушках проверки `--bad`, в ролике нет |
| `mirror` | `false`, `true` | зеркало мира: места и повороты устройств, дерево под ними, общий план клиента (планшет справа, телефон слева). Содержимое экранов, подписи и логотип не отражаются | `false` (1, 3), `true` (2) |
| `light` | `left`, `right` | сторона источника в кадре: спад света на столе, тени устройств, блики на ребре и стекле; `mirror` её не меняет | `left` (1, 3), `right` (2) |
| `drift` | `push`, `sweep` | камера в проходе клиента. `push` как было: наезды по прямой. `sweep`: диагональный проезд от стороны телефона к стороне планшета (слева направо при `mirror`, справа налево без него), те же ключевые точки в те же моменты (телефон 1T, общий план 2T, корзина 3T+0,6, касание, страница заказа, итог), начало прохода сбоку от телефона | `push` (1, 2), `sweep` без `mirror` (3) |
| `palettePreset` | `dark`, `light`, `color` | цвета экранов (сайт снимается в них), акцент, подписи, подложка под подписями, карточкой и обложкой, фото стола | `dark` (1, 2), `light` (3); `color` не проверена |
| `cam` | числа камер | правка кадра для одной комбинации, если она ломает зону или подпись | 2: `{"K0Y": 885}` |

Проверенные комбинации (заглушки, 19.11.2026):

| № | enterFrom | mirror | light | drift | palettePreset | cam |
|---|---|---|---|---|---|---|
| 1 | top | false | left | push | dark | — |
| 2 | left | true | right | push | dark | `K0Y` 885 |
| 3 | top | false | left | sweep | light | — |

Другие сочетания (например, `sweep` с `mirror`, палитра `color`, `enterFrom: right` в ролике) не проверены: прогнать `run_checks.sh` и при сбое править `variant.cam`, а не проверку.

## Что проверять

Скриптами (`run_checks.sh`, каждая проверка сначала на плохом входе): зоны Reels 14–65 % по тактам, буквы событий на экранах от 12 px в 360, заглавные подписей от 20 px в 360 и контраст от 7:1, поля 6 % (`caption_margins.py --safe 65`), обрезанные слова, участки без текста до 1,5 с по таймлайну из кода, касания и карточка на долях, линейных кривых нет, логотип не уже 40 % и контраст от 3:1, обложка в плитках 1:1 и 3:4 в 120 px, громкость −14 ±1 LUFS и true peak до −1 dBTP, звук и видео одной длины, вариант (`variant_check.py`: захваты въезжают с нужной стороны и сняты в цветах палитры; камера в ключевых точках совпадает с `push` до 1 мирового px, `sweep` отходит между ними не меньше чем на 30; телефон на общем плане с нужной стороны планшета; освещённая сторона стола светлее другой не меньше чем на 10 %; на экранах нет отражения). Лист `out/crop360.png`: все кадры раскадровки, карточка и обложка в 360 px, смотреть как на телефоне. OCR на пометки «демо» и чужие бренды остаётся в проекте (Tesseract, для кириллицы нужен словарь rus).

Человек на настоящем телефоне: читается ли подпись за секунду, не давит ли на экран, совпадают ли касания и карточка с долями, ровно ли затухает конец, читается ли контакт за время карточки.

## Проверка сборки шаблона

Проверка сборки, 19.11.2026: копия шаблона вне репозитория, пакеты проекта Scent Harbor (Remotion 4.0.544, React 19.3.1), выдуманные данные из `config.json` и заглушки `make_placeholders.py` (синтетические экраны, текстура вместо фото, слово вместо логотипа, метроном вместо трека).

Команды: `python scripts/make_placeholders.py`, `python scripts/music_cut.py`, `sh scripts/build_reel.sh`, `CLIP_MAKER=… sh scripts/run_checks.sh`.

- Сборка: четыре такта отрендерены и сведены, `out/reel.mp4` H.264 1080×1920, 30 к/с, 384 кадра, 12,80 с; AAC 48 кГц, 12,783 с, расхождение 17 мс (меньше кадра).
- Громкость: −14,21 LUFS (ffmpeg loudnorm −14,47), true peak −1,28 dBTP.
- Раскадровка: зоны, буквы событий и обрезанные слова OK. Плохой вход (хук ниже на 70 px, строка правее на 120 px) пойман: 3 FAIL.
- Поля подписей 6 %: 0 нарушений в 11 кадрах, плохой вход: 1 нарушение.
- Крупные подписи: заглавные 20,7 / 20,3 / 24,3 px в 360, контраст 17,2:1, ключевые слова 11,4:1.
- Участки без текста: самый длинный 1,30 с. Линейных кривых нет.
- Логотип 48 % ширины, контраст 3,55:1. Обложка проходит в плитках 1:1 и 3:4, заглавная в плитке 120 px 10,6 px.

Что нашла проверка:
1. С запасным шрифтом браузера (без `public/fonts`) заглавные подписей выходят 18,7–19,3 px и проверка падает. С Playfair Display проходит. Шрифты сайта класть до первого рендера.
2. Логотип должен быть обрезан по знаку с полями 8 px, как его режет `logo_alpha.py`: карточка считает ширину от этого. Логотип в углу пустого холста получается уже 40 %.
3. Ограничитель в `music_cut.py` после срезания поднимал громкость обратно, и true peak выходил +0,21 dBTP. Исправлено опережающим ограничителем без повторного усиления.

Кадры раскадровки базовой комбинации совпадают с прошлой сборкой шаблона до 2/255 на пиксель: подложка подписи взяла цвет палитры (10,8,7) вместо прежнего (8,6,5).

Что потребовала светлая палитра (числа палитры, не проверки): плотная светлая подложка за подписью (`halo` 0,95 / 0,75), слабое затемнение стола к краям (`shade` 0,35), ключевые слова `#12352c`. Без этого тёмные подписи давали 3,7:1 и 2,4:1.

Проверки `caption_big.py` и обложки стали учитывать палитру (ключевые слова по ближайшему из двух цветов подписи, контраст обложки по модулю). Пороги прежние.

Не проверено в шаблоне: `capture/capture.js` против живого сайта (сайта для примерных данных нет; логика та же, что снимала Scent Harbor, переписана под `config.json`), выбор кадров для другого сайта (точки `layout` и камеры подбираются заново по шагу 4), вход вариантов в настоящей сборке сайта (`?adEnter=`, CSS-переменные палитры), палитра `color`, `enterFrom: right` в ролике, `sweep` с `mirror`.
