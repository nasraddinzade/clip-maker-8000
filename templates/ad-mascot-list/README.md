# Шаблон рекламы «маскот плюс подборка» (Remotion)

Код ролика ai-helper-01 («Три дела ИИ-помощника», 22.11.2026), вынесенный по каркасу `reference/ad-template-mascot-list.md`. Все данные ролика лежат в `config.json`, в нём сейчас пример ai-helper-01. Вёрстка, переходы, маскот, звук и проверки уже проверены на этом ролике; от ролика к ролику меняются только конфиг, голос, трек, палитра и логотип. Промты двух заходов: `prompts/ad/mascot-list_two_pass.md`.

## Порядок

1. Скопируй шаблон в проект (`projects/<имя>/reel` или рядом с копией правил), `npm ci` (версии закреплены без `^`). Remotion 4.0.544, лицензия как в `video-ad-craft`.
2. Цвета и эстетику спроси у человека (`CLAUDE.md`, «Цвета и эстетика»): покажи `--props='{"theme":"sky"}'` и другие темы одними и теми же кадрами. Новая палитра это новая запись в `src/theme.ts`.
3. Заполни `config.json`: тексты хука, шагов, экранов, наклеек, финала, карточки. Подпись заголовка в одну строку не длиннее около 16 знаков при 96 px, иначе две строки (`lines`).
4. Голос: `python scripts/voice_probes.py путь/.env` (пробы слушает человек), затем `voice_full.py`, затем `.venv-whisper/Scripts/python scripts/whisper_check.py` (расхождения проверить на слух), затем `python scripts/build_timeline.py` (печатает сцены; шаг короче 8 с помечен).
5. Музыка: `python scripts/beat.py music/track.mp3`, затем `python scripts/mix.py` (пишет `music.start` в конфиг).
6. Стоп-кадры: `npx remotion still --port=3417 src/index.ts Reel out/f.png --frame=N` на хук, каждый шаг, карточку; лист в 360 человеку.
7. Ролик: `bash scripts/render.sh имя`, затем один раз `bash checks/run_checks.sh out/имя.mp4`. Ревьюер свежим субагентом один раз (`video-qa`).

## Якоря в `config.json`

Любое время задаётся якорем, а не числом:
- `«пишет»` — начало слова голоса (по меткам Whisper, первое такое слово);
- `«клиент@11»` — первое такое слово после 11-й секунды ролика;
- `«клиент@11:e»` — конец этого слова;
- `«принять@21+0.1»`, `«уточнит-0.65»` — сдвиг в секундах;
- `«#step2»`, `«#final»`, `«#card»` — начало сцены; `«#step1.title1»` — время второго слова заголовка шага 1;
- `«3.6»` — секунды.

Слово ищется без учёта регистра и «ё»; если не найдено, рендер падает с названием слова. Сцены режет `build_timeline.py` по маркерам `steps[].marker`, `final.marker`, `card.marker`.

## Поля `config.json`

- `video`: `fps`, `voiceOffset` (голос с 0,2 с, кадр 0 уже обложка), `cardHold` (карточка 3 с).
- `voice`: голос, модель, `stability`, `seed`, `text` (произнесённая форма, с аудиотегами v3), `file`.
- `music`: `file`, `bpm`, `beat`, `phase` (пишет `beat.py`), `start` (пишет `mix.py`), `mix` (A или B).
- `mascot`: `character` (`bell`, `r`, `bubble`), `x` 85 и `scale` 0,74 при вёрстке каркаса; другой маскот проверить рамкой всех поз (`run_checks.sh`).
- `layout`: карточка экрана и место наклеек, числа каркаса; менять только с прогоном проверок.
- `hook`: `title` (обложка, без появления), `swap` (второй заголовок с предложением: кто и что, по словам голоса), `fan`, `stickers`.
- `steps[]`: `marker` (слово, с которого начинается шаг) и `title` (`words` на экране, `voice` слова голоса для проявления, `lines`, `accent`).
- `screens[]`: `chat` (шапка, сообщения с `at` и `typing`, `scroll`), `order` (строки, кнопка, `tap`), `post` (картинка `image`, подпись печатается с `text`, кнопка, `tap`, своя картинка `picture`). У каждого `enter` и `exit`.
- `stickers[]`: `text` (заглавные, до 9 знаков), `at` (встаёт на ближайшую долю), `until`, `dx`, `rot`, `dark`.
- `mood[]`: эмоция маскота по якорям, смена каждые 1–2 с; `rings` (дуги «дзинь»), `press` (нажатие кнопки на макушке).
- `final`: `marker`, `title`, `fan`. `card`: `marker`, `logo`, `lines` (до трёх, `{"mark": "…"}` под чертой), `contact`.

## Проверено на шаблоне

Конфиг ai-helper-01 в шаблоне даёт тот же таймлайн, что ролик проекта (все сцены и времена слов), а кадры совпадают с кадрами проекта v7 (`reference/ad-template-mascot-list.md`, «Статус»).
