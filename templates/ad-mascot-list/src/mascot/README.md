# Маскот студии Ramex (переиспользуемый)

SVG-компонент Remotion. Кадр чистая функция пропсов: таймеров и CSS-анимаций нет, эмоция и моргание задаются числами от номера кадра снаружи.

```tsx
<svg width={1080} height={1920}>
  <Mascot character="r" emotion="joy" x={200} y={600} scale={1.7} blink={0} uid="host" />
</svg>
```

| Файл | Что внутри |
|---|---|
| `config.ts` | эмоции (`EMOTIONS`: глаза, брови, рот, румянец, руки, наклон), палитры персонажей (`PALETTES`), общие цвета (контур, рот, белки) |
| `parts.tsx` | слои: глаз, бровь, рот, рука в два прохода (контур и заливка), кисти (варежка, раскрытая, указательный, большой палец) |
| `characters.tsx` | тела трёх персонажей: силуэт, геометрия лица, плечи |
| `Mascot.tsx` | сборка слоёв, маска корня руки (рука выходит из тела без шва, перед лицом контур виден) |

- Холст персонажа 400×560 единиц, низ y 560 это линия «по пояс», тело может уходить ниже.
- Эмоции: `calm`, `pointUp`, `joy`, `surprise`, `think`, `wink`. Новая эмоция это новая строка в `EMOTIONS`.
- `face` переопределяет отдельные слои поверх эмоции (например, рот `talk` во время речи при любой эмоции).
- `blink` 0..1 закрывает открытые глаза.
- Несколько маскотов в одном кадре: разный `uid`, иначе совпадут id масок.
- Терракота логотипа #BE4522 в маскоте не используется.
