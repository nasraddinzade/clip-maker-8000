# Шаблон кода: эссе «тушь на бумаге»

Рендерер «Пяти колец» (v14, 19.11.2026) без сцен ролика. Код к каркасу `reference/essay-template-ink.md`, промт `prompts/essay/ink_template.md`. Для нового эссе хватает этого README и промта.

Стек: p5.js (WEBGL) и p5.brush для кисти, GLSL для бумаги и размывок, Vite и Puppeteer для рендера по кадрам, ffmpeg для звука и сборки.

## Что внутри

| Путь | Что это |
|---|---|
| `config.json` | всё, что меняется от ролика к ролику: тексты, подписи, знаки, раскладки, тайминг, голос, музыка, логотип. В шаблоне выдуманный пример: две главы и финал |
| `src/main.js` | кадр по номеру (`window.__renderFrame(n)`), проходы рисования, экранные подписи, превью, выгрузка рамок для проверок |
| `src/timeline.js` | таймлайн от голоса: длина сцены = вступление + голос + хвост, целое число кадров |
| `src/scroll.js` | камера: свиток глав одна под другой, переезды, ключи `{s, x, y, z, lin}`, лёгкое «дыхание» |
| `src/ink.js` | кисть на p5.brush: мазок с нажимом, волоски, сухой конец, живая линия |
| `src/calligraphy.js` | знак кистью по порядку черт KanjiVG, профиль нажима по типу черты |
| `src/seal.js` | печать (киноварь, неровная краска, непропечатка) |
| `src/signature.js` | подпись художника: логотип, впечатанный в бумагу, и строка рядом |
| `src/kit.js` | шапка главы (знак, печать), горы, брызги, туман, раскладка подписи, реестр рамок для проверок |
| `src/type.js` | текст с разрядкой |
| `src/gl/shaders.js`, `src/gl/layers.js` | бумага васи в мировых координатах, размывки по маске (растекание по волокнам, зерно), туман, пост (зерно, виньетка) |
| `src/scenes/example.js` | сцена-образец: знак главы, предмет, событие на слово, удержание. Вверху файла описан весь интерфейс модуля сцены |
| `src/scenes/finale.js` | финал-образец: линия кистью, большая печать, подпись художника |
| `scripts/voice.mjs` | голос → `timing.json` → дорожка (голос −14 LUFS, музыка ровным слоем, итог −14 LUFS) |
| `scripts/render.mjs` | рендер кадров в 3 вкладки → mp4 со звуком и петлёй |
| `scripts/snap.mjs` | снимки отдельных кадров с отладочными флагами |
| `scripts/export_geometry.mjs` | рамки подписей и элементов по кадрам и таблица событий для проверок |
| `scripts/kanji.mjs` | знаки из `config.json` → `src/data/kanji.json` из SVG KanjiVG |
| `checks/` | проверки проекта, которых нет в `tools/` (список ниже, «Что проверять») |
| `index.html`, `vite.config.js`, `package.json`, `.gitignore`, `timing.json` | превью, сервер, зависимости, что не коммитить, заглушка таймлайна |

## Как начать

```bash
cp -r templates/essay-ink projects/<имя>
```

```bash
cd projects/<имя> && npm install
```

Папка `projects/` в репозиторий не попадает. Дальше: положи файлы («Что положить»), заполни `config.json`, напиши сцены и запускай команды по порядку («Команды по порядку»).

## Что положить (в репозиторий не кладётся, `.gitignore`)

В репозиторий шаблона они не входят. Это чужие данные, тяжёлые файлы или данные заказчика.

| Файл | Куда | Формат и откуда |
|---|---|---|
| Шрифты подписей | `public/fonts/` | TTF с кириллицей. На «Пяти кольцах» Cormorant Garamond Light, Regular, Medium, Italic, SIL OFL 1.1 (Google Fonts). Рядом положи файл лицензии `OFL.txt`. Имена файлов записаны в `config.json → fonts` |
| Знаки KanjiVG | `assets/kanjivg/` | SVG из выпуска KanjiVG (github.com/KanjiVG/kanjivg, раздел Releases, архив `kanjivg-<дата>-main.zip`, папка `kanji/`). Можно всю папку или только нужные файлы. Имя файла — код знака в hex из 5 цифр: 水 → `06c34.svg`, 空 → `07a7a.svg`. Файлы с суффиксом (`06c34-Kaisho.svg`) не нужны |
| Логотип | `public/logo/` | PNG с прозрачным фоном, ширина в 2–4 раза больше экранной (на «Пяти кольцах» 940 px при показе 240). Фон снимай без изменения формы и цвета. Путь в `config.json → logo.file`, `null` — без логотипа |
| Голос | `voice/<id>.wav` | по файлу на сцену, `id` из `config.json → scenes`. Тишину по краям скрипт обрезает сам. Синтез, выбор голоса, ударения, нарезка по самой тихой точке — навык `video-voice` |
| Фразы и слова голоса | `voice/<id>.json` | необязательно, но без него события по словам считаются по доле букв. Формат ниже, раздел «Голос» |
| Музыка | `music/track.mp3` | трек с лицензией на все площадки, выбирает человек на слух. Путь в `config.json → music.file` |

## Переменные `config.json`

| Ключ | Что это |
|---|---|
| `title`, `output` | название (для себя) и путь итогового mp4 |
| `video` | 1080×1920, 30 fps для Reels и Shorts |
| `timing` | `voiceDelay` (вступление до голоса, 1,5 с), `tail` (хвост, 1,2 с), `travel` и `travelPre` (переезд между главами и его часть в хвосте прошлой), `headerStart` (когда знак начинает писаться, 0,05 с), `loopFrames` (сколько последних кадров уходит в кадр 0, 10 = 0,33 с) |
| `fonts` | файлы шрифтов в `public/` по ключам `light`, `regular`, `medium`, `italic` |
| `logo` | `file`, `width` (ширина на экране), `spot` (правый край и верх подписи в момент полной силы, экранные px), `fade` (проявление, с), `press` и `grain` (неровность краски и зерно), `studio` (строка рядом: текст, начертание, кегль, разрядка, цвет), `baseline` (линия строки от верха логотипа) |
| `scenes[]` | по сцене на главу и финал: `id`, `module` (файл `src/scenes/<module>.js`), `seed`, `fallbackDuration` (длина до голоса), `kanji`, `caption` (`title` капителью, `text` основная строка), `captionLayout` (места строк: `x`, `y`, `align`, `wrap`, `size`), `narration` (текст голоса, фразы делятся по . ! ? …), `pauses` (паузы между фразами), `tail`. Сцене-образцу нужны ещё `layout` (места знака, печати, предмета, капли), `object` и `event` (`phrase` с 1 и `word`). Финалу нужны `seal` (`char`, `size`, `x`, `y`) и `signatureOffset` (начало подписи от конца файла голоса; возьми из огибающей голоса: последний момент громче −35 dBFS) |
| `voice` | `engine`: `silence` — тишина по числу букв, чтобы собрать ролик до голоса; `files` — готовый голос из `voice/`. Ещё `sentencePause` и `charsPerSecond` для тишины |
| `music` | `file`, `fadeIn`, `fadeOut`, `belowVoiceDb` (музыка ровным слоем на столько дБ тише голоса, коридор −21…−23) |
| `kanjiExtra` | знаки, которых нет в `kanji` и `seal`, но которые рисует сцена |
| `checks.zoneElements` | начала имён элементов, которые нельзя прятать под кнопки: знаки, печати, всё, что называет голос |

Числа и правила за ними — в каркасе `reference/essay-template-ink.md`, разделы 1–5. Каждую задуманную паузу и каждое решение человека записывай в `brief.md`, раздел «Решения по сценам», с меткой [РЕШЕНИЕ БРИФА].

## Сцены

Новая глава — новый файл в `src/scenes/` по образцу `example.js`, образ по сценарию ролика. Интерфейс модуля и `ctx` описаны вверху `example.js`. Правила, которые образец уже показывает:
- время берётся от голоса (`ctx.phrase(n)`, `ctx.wordAt(n, "слово")`), а не числом секунд;
- предмет готов до своего слова, событие ровно на слове, после главного образа только удержание;
- всё, что называет голос, попадает в `keepout(ctx)` с `t0`, иначе проверка зон его не видит;
- состояние хранится в `scene.state`: один модуль может обслуживать несколько глав;
- случайность только через `rng(seed)` и `ctx.reseed(id)`, кадр зависит только от номера.

Сцены «Пяти колец» (утёс, гора с хижиной, капля и круги, дуэль, бамбук, энсо) как образы не переносить. Код их приёмов лежит в проекте ролика (раздел «Что осталось в проекте»).

## Голос

`voice/<id>.json`, времена в секундах от начала файла голоса после обрезки тишины:

```json
{ "parts": [
  { "start": 0.0, "duration": 1.0, "text": "Глава первая.", "words": [{ "w": "Глава", "start": 0.0, "end": 0.5 }] },
  { "start": 1.4, "duration": 1.2, "text": "Вода мягкая, но камень ей уступает.", "words": [{ "w": "камень", "start": 2.0, "end": 2.3 }] }
] }
```

У ElevenLabs v3 весь текст идёт одним запросом с таймкодами символов. Из них собираются фразы и слова, файл режется на сцены по самой тихой точке (`video-voice`).

## Команды по порядку

| Шаг | Команда | Что получится |
|---|---|---|
| 1 | `npm install` | пакеты из `package.json` |
| 2 | `npm run kanji` | `src/data/kanji.json` для всех знаков из `config.json` |
| 3 | `npm run voice` | `timing.json`, `build/audio/narration.wav` и стем голоса `build/audio/voice.wav` |
| 4 | `npm run dev` | превью на http://localhost:5173: ползунок кадра, выбор сцены, Play со звуком, стрелки ← → (Shift — на секунду) |
| 5 | `npm run stills` | стоп-кадры глав `out/stills/scene_N.png`. Это **остановка прохода 1** (каркас, раздел 7) |
| 6 | `npm run render` | кадры `build/frames`, ролик `out/essay.mp4` со звуком и петлёй. `--from A --to B --frames-only` — только часть кадров, `--reuse` — не перерисовывать готовые |
| 7 | `npm run geometry` | `out/geometry.json` (рамки и события), `out/captions.json` и `out/elements.json` для `tools/caption_margins.py` |
| 8 | `node scripts/render.mjs --frames-only --nocap --no-audio` | кадры без подписей `build/frames_nocap` для проверок туши под подписью |
| 9 | проверки ниже | отчёт по формату `video-qa` |

`npm run snap -- --frames 120,240 --nograin` снимает отдельные кадры. `--q "имя=значение"` передаёт параметр странице: так сцена показывает варианты (`globalThis.__PARAMS.get("имя")`) на стоп-кадрах до решения человека.

## Что проверять

Обязательный набор и формат отчёта задаёт `video-qa`. Каждую новую проверку сначала прогони на заведомо плохом входе. Скрипты из `tools/` клона clip-maker-8000, путь `../../tools/`:
- `audio_check.py lengths|loud|joints`;
- `caption_margins.py out/captions.json --ui reels --elements out/elements.json`;
- `flash_detector.py`;
- `accent_area.py`;
- `frames_every.py`;
- `crops3x3.py`;
- `motion.py`.

Проверки шаблона (`python checks/<имя>.py`, нужны Python 3.10+, numpy, Pillow, scipy, для `check_effect_edge.py` ещё opencv-python):

| Скрипт | Что проверяет |
|---|---|
| `check_ui_elements.py out/geometry.json` | знаки, печати и названное голосом вне зон интерфейса в покое. Плохой вход строит сам: опускает нижний элемент на 300 px |
| `check_caption_ink.py out/geometry.json build/frames_nocap` | пока подпись видна, в её рамке нет изображения |
| `check_intro.py out/geometry.json build/frames_nocap` | первая тушь знака ≤ 0,3 с после смены сцены, подпись ≤ 0,3 с после начала фразы |
| `check_loop.py out/essay.mp4` | хвост плавно приходит к кадру 0 |
| `check_loop_title.py --finale build/frames/f_<N>.png --geom out/geometry.json` | на месте названия первой сцены к петле чистая бумага. N = кадров всего − `loopFrames` − 1 |
| `check_signature.py --geom out/geometry.json --hex <цвет логотипа>` | подпись художника: ширина, зоны, расстояния, проявление 0,4–0,6 с, в полную силу ≥ 1,8 с до петли, красное с печатью ≤ 3,5 %, штрих строки рядом |
| `check_stroke_360.py --font … --size … \| --image … --box …` | штрих букв в 360 px: медиана ≥ 1 px. Делай с запасом, около 1,5 px |
| `check_cinnabar.py кадр.png --seal x0,y0,x1,y1` | красного вне печати мало, печать — самый яркий красный |
| `check_effect_edge.py --on ON.png --off OFF.png` | эффект по краю массы (тлеет, светится): разрывы по разнице с кадром без эффекта, худшая сторона |
| `check_straight_edges.py --dir build/frames --frames 0:N:5` | прямые края размывок и масок |
| `check_paper_clean.py out/geometry.json build/frames_nocap` | под подписью бумага без волокон |
| `check_blank_paper.py build/frames` | интервалы почти пустого листа. Порог 6 % подобран на «Пяти кольцах», подбери свой на заведомо пустых кадрах |

Глазами, без скрипта:
- случайные россыпи (капли, брызги, пятна) в 360 px на лица и фигуры;
- молодые элементы в 100 %: новый мазок не появляется точкой или чёрточкой;
- подписи на телефоне.

- **Громкость.** С тишиной вместо голоса дорожка −36 LUFS, это ожидаемо. −14 LUFS дал только прогон `engine: files`.
- **`check_effect_edge.py`.** В примере нет эффекта по краю.

- **Чужая машина.** Не проверены macOS, Linux и машина без GPU. В `render.mjs` задан `--use-angle=d3d11`, это ключ Windows.
- **Ролик целиком.** Глазами шаблон смотрели только по стоп-кадрам, полного ревью ролика не было.

## Что осталось в проекте «Пять колец» и почему

- **Сцены ch0–ch6.** Это образы ролика, каркас запрещает их переносить. Приёмы (раскол массы щелью, тлеющий край, капля и круги, бамбук, энсо) живут в шейдере размывки (`uSplit`, `uChar`) и в коде этих сцен на машине автора, `D:\мусаси\src\chapters`.
- **Сборка v4–v14 и сравнения версий** (`assemble_v*.sh`, `compare_v*.py`). Это история одного ролика. Петля перенесена в `render.mjs`.
- **Синтез голоса** (`scripts/voice/*.py`, Silero, Qwen, ElevenLabs). Движки и ключи свои у каждого ролика, у Silero некоммерческая лицензия. Здесь только приём готовых файлов.
- **Узкие замеры** (`check_motion.py`, `measure_region.py`, `check_flashes.mjs`, `check_captions.mjs`). Есть общие аналоги в `tools/` (`motion.py`, `flash_detector.py`, `caption_margins.py`).
