# Проверки и отчёт

Скрипты в `tools/`, описание в `tools/README.md`.

## Обязательные проверки

| Проверка | Инструмент | Критерий |
|---|---|---|
| Длины и формат | `audio_check.py lengths` | 1080×1920, 30 fps, видео равно звуку ±1 кадр |
| Громкость | `audio_check.py loud` | −14 ±1 LUFS, true peak не выше −1 dBTP |
| Стыки звука | `audio_check.py joints` | тишина голоса на стыке, отрезки по 3 с прослушаны человеком |
| Кадры каждые 2 с | `frames_every.py` | лист просмотрен, первый кадр не пустой |
| Кропы 3×3 | `crops3x3.py` | кадр из середины каждой сцены, все 9 клеток описаны |
| Переходы | 8 кадров на переход | нет полос, обрывов, наложений на подпись |
| Подписи | `caption_margins.py --ui <площадка>` | 0 нарушений во всех кадрах |
| Вспышки | `flash_detector.py` | 0 вспышек, прогон на заведомо плохом входе находит хотя бы одну |
| Движение | `motion.py` и таблица событий | событие хотя бы раз в 2 с, метрика только сигнал тревоги |
| Ударения | таблица из словаря | показана человеку |

Каждую новую проверку сначала прогони на заведомо плохом входе. Детектор, который ни разу не сработал, ничего не доказывает.

## Ревью свежим взглядом

Перед показом полного ролика запусти субагента, который не видел твоих правок. Дай ему только пути к листам, кропам и брифу. Попроси найти то, что заказчик попросит переделать, со ссылками на номера кадров. Его находки включи в отчёт без смягчений.

## Формат отчёта

```
Статус: готово / готово с исключениями / не готово
Что показываю: пути к файлам
Что изменилось: пункты, у каждого кроп или кадр «до/после»
Проверки: проверка → результат → критерий
НЕ прошло: пункты с цифрами (обязательно, даже если пусто)
НЕ проверено мной: что требует глаз или ушей человека
Отличия от плана: пункты
Вопрос: одно решение, которое нужно от человека
```

## Запреты

- Не пиши «исправлено» без кропа в 100 % того места.
- Не подгоняй решение под порог метрики.
- Не прячь непрошедшие проверки в середину текста.
