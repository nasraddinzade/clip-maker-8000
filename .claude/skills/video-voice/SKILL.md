# Голос ролика

Подробности по движкам и доказательства в `reference/tts.md`.

## Выбор

1. Спроси, будет ли ролик коммерческим. Проверь лицензию движка по файлу LICENSE, а не по README.
2. Живой голос человека звучит естественнее любого бесплатного синтеза. Предложи его первым, если стиль спокойный и повествовательный.
3. Для синтеза на русском (проверено на «Пяти кольцах», ноябрь 2026, CPU без видеокарты).
   - Самый человечный на слух Qwen3-TTS (Apache-2.0, голос Dylan). Ударение не задаётся, знак U+0301 ломает слова, интонация иногда уходит не туда. Работай дублями (3 на кусок, разные seed), режь длинные предложения по запятым, выбор за человеком. 0.6B считает около 45 с на фразу.
   - ESpeech (F5-TTS) понимает «+» для ударения и обучен на русском. Лицензия неясна. На карточке apache-2.0, но базовая модель не названа, а официальные веса F5-TTS некоммерческие. Около 150 с на фразу.
   - Chatterbox Multilingual (MIT) клонирует голос по образцу. Русский слабее, ударения сам. В выходе неслышный водяной знак. Около 35 с на фразу.
   - Silero v5 надёжен по ударениям со словарём, но звучит роботизированно, и лицензия некоммерческая. Обработка (эквализация, паузы, комната) машинность не убирает.
   - Piper показывает фонемы, это единственная объективная проверка ударения. Голоса dmitri и denis на CC0-датасетах.
   - Платно с явной разметкой ударений Яндекс SpeechKit.
   - Клон берёт тембр из образца. Синтетический образец даёт синтетический клон, лучше 12–15 с живого голоса человека.
4. Сделай 2–3 пробы на одном и том же тексте сцены. Склей пробы каждого движка в один файл с паузами и выровненной громкостью. Выбирает человек на слух.

## Ударения

- Текст разбей на предложения. Один файл на предложение, кэш по тексту с ударениями.
- Словарь `pronunciation.json` для всех многосложных слов.
- Доказательство, по убыванию силы.
  1. Фонемы с маркером ударного слога (Piper/espeak).
  2. Детерминированный движок. Синтез без знаков побайтно равен синтезу с явно правильными знаками.
  3. Человек на слух по таблице «слово → ударение».
- Различие «правильный ≠ неправильный» доказывает только, что знак учитывается. Не выдавай его за проверку.

## Живая запись

- Дай сценарий по фразам с целевой длительностью, знаками ударения и паузами.
- Памятка. Тихая комната без эха, телефон на расстоянии ладони, одна фраза за дубль, каждую фразу дважды.
- Обработка. Шумоподавление, срез ниже 70–80 Гц, лёгкая эквализация, компрессия 2:1, выравнивание громкости, обрезка тишины. Без реверберации и эффектов. Исходники не трогай.

## Тайминг и сведение

- Длина сцены равна вступлению, голосу и хвосту. Голос не ускоряй больше чем на 5 %.
- Покажи таблицу «сцена → было → стало» и предложи, какие сцены перерендерить. Сам не перерендеривай.
- Голос −14 LUFS в два прохода `loudnorm`, true peak не выше −1 dBTP.
- Музыка с нарастанием и затуханием, приглушение под речью через `sidechaincompress`. Уровень музыки мерь отдельной копией.
- После склейки сверяй длину с суммой частей, расхождение больше 80 мс считается ошибкой.
- Стыки проверяй по дорожке голоса без музыки (`tools/audio_check.py joints`).

## Остановка

Покажи пробы, таблицу ударений, длину ролика по голосу и строку «на слух не проверено, проверьте слова …». ОСТАНОВИСЬ.
