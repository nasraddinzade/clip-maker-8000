# Голос ролика

Подробности по движкам и доказательства в `reference/tts.md`.

## Выбор

1. Спроси, будет ли ролик коммерческим. Проверь лицензию движка по файлу LICENSE, а не по README.
2. Живой голос человека звучит естественнее любого бесплатного синтеза. Предложи его первым, если стиль спокойный и повествовательный.
3. Для синтеза на русском (проверено на «Пяти кольцах», ноябрь 2026, CPU без видеокарты).
   - Лучший итог по ровности на слух у ElevenLabs eleven_v3, голос Maxim из библиотеки, весь текст одним запросом. Платно (Starter), коммерция разрешена на платном тарифе. Ударение не задаётся, знак U+0301 портит подачу, см. раздел «ElevenLabs v3» ниже и `reference/lessons.md`, раздел 03.
   - Самый человечный из бесплатных на слух Qwen3-TTS (Apache-2.0, голос Dylan). Ударение не задаётся, знак U+0301 ломает слова, интонация иногда уходит не туда. Работай дублями (3 на кусок, разные seed), режь длинные предложения по запятым, выбор за человеком. 0.6B считает около 45 с на фразу.
   - ESpeech (F5-TTS) понимает «+» для ударения и обучен на русском. Лицензия неясна. На карточке apache-2.0, но базовая модель не названа, а официальные веса F5-TTS некоммерческие. Около 150 с на фразу.
   - Chatterbox Multilingual (MIT) клонирует голос по образцу. Русский слабее, ударения сам. В выходе неслышный водяной знак. Около 35 с на фразу.
   - Silero v5 надёжен по ударениям со словарём, но звучит роботизированно, и лицензия некоммерческая. Обработка (эквализация, паузы, комната) машинность не убирает.
   - Piper показывает фонемы, это единственная объективная проверка ударения. Голоса dmitri и denis на CC0-датасетах.
   - Платно с явной разметкой ударений Яндекс SpeechKit.
   - Клон берёт тембр из образца. Синтетический образец даёт синтетический клон, лучше 12–15 с живого голоса человека.
4. Сделай 2–3 пробы на одном и том же тексте сцены. Склей пробы каждого движка в один файл с паузами и выровненной громкостью. Выбирает человек на слух.
5. Первый критерий человека. Тембр, интонация и манера читать не меняются на протяжении всего ролика. Для спокойной притчи нужна ровная подача без театральности и без вопросительных ноток там, где фраза не вопрос. Фразы вроде «Старый мастер меча» читаются ровно, без смыслового ударения на первом слове.
6. Долгий синтез на CPU, больше получаса, покажи человеку заранее с оценкой времени и предложи быстрый вариант через API. Человек не принимает многочасовые ожидания.

## ElevenLabs v3

- Ключ в `.env` как `ELEVENLABS_API_KEY`. Не печатай, не логируй, проверь скриптом, что его нет в выходных файлах. Права ключа минимальные. Text to Speech, Voices (чтение), User (чтение). Библиотечный голос работает по id. Алиасы произношения требуют права на запись словарей.
- До выбора голоса прочитай его условия в библиотеке. Ставка, срок уведомления, коммерция, модерация на лету, не клон ли реального диктора.
- Пробы на одних и тех же трёх фразах у 4–5 голосов, плюс один голос на v3 против v2. Склей в файл на голос с одинаковой громкостью и скажи, где что начинается.
- Настройки одинаковые для всех запросов. `stability` на самом высоком значении, `style` 0, `speed` по умолчанию, один `seed`. `previous_text` и `next_text` v3 не принимает.
- Весь текст одним запросом через эндпоинт с таймкодами по символам. Режь на сцены по самой тихой точке у границы. Запрос на сцену даёт слышимые стыки, не используй его для основной озвучки.
- Не вставляй U+0301 над словами ради ударения. Подача меняется целиком, длина озвучки плавает (53,3 против 60,1 с на том же тексте). Если ударение в слове неверное, единственный путь перегенерация всего текста с новым seed и согласие человека, потому что длины сцен поплывут.
- Начала слов в таймкодах после пауз приходят раньше на 0,2–0,6 с, иногда до 1,3 с. Якорь бери по концу слова или уточняй по огибающей.

## Ударения

- Текст разбей на предложения. Один файл на предложение, кэш по тексту с ударениями.
- Словарь `pronunciation.json` для всех многосложных слов.
- Доказательство, по убыванию силы.
  1. Фонемы с маркером ударного слога (Piper/espeak).
  2. Детерминированный движок. Синтез без знаков побайтно равен синтезу с явно правильными знаками.
  3. Человек на слух по таблице «слово → ударение».
- Различие «правильный ≠ неправильный» доказывает только, что знак учитывается. Не выдавай его за проверку.

## Живая запись

- Дай сценарий по фразам с целевой длительностью, знаками ударения и паузами.
- Памятка. Тихая комната без эха, телефон на расстоянии ладони, одна фраза за дубль, каждую фразу дважды.
- Обработка. Шумоподавление, срез ниже 70–80 Гц, лёгкая эквализация, компрессия 2:1, выравнивание громкости, обрезка тишины. Без реверберации и эффектов. Исходники не трогай.

## Тайминг и сведение

- Длина сцены равна вступлению, голосу и хвосту. Голос не ускоряй больше чем на 5 %.
- Хвост финальной сцены с большим знаком или печатью увеличь до 2–2,6 с, иначе кадр обрывается. Напиши в отчёте, что это исключение.
- Перед финальной фразой пауза около 1,0 с. Меряй итоговую паузу вместе с тишиной вокруг.
- Тишину по краям сцен срезай с запасом 30 мс, исходники не трогай. Громкость сцен выравнивай статическим усилением, без компрессии, разброс до 0,5 LU.
- Покажи таблицу «сцена → было → стало» и предложи, какие сцены перерендерить. Сам не перерендеривай.
- Голос −14 LUFS в два прохода `loudnorm`, true peak не выше −1 dBTP.
- Музыка с нарастанием и затуханием, приглушение под речью через `sidechaincompress`. Уровень музыки мерь отдельной копией.
- После склейки сверяй длину с суммой частей, расхождение больше 80 мс считается ошибкой.
- Стыки проверяй по дорожке голоса без музыки (`tools/audio_check.py joints`).

## Остановка

Покажи пробы, таблицу ударений, длину ролика по голосу и строку «на слух не проверено, проверьте слова …». ОСТАНОВИСЬ.

Файлы для человека на слух. Целая дорожка с таймкодами проверяемых слов или куски по границам фраз без перекрытий. Не режь куски по 3 секунды вокруг слов, они рвут фразы и повторяют слова (случай «Пяти колец», `reference/lessons.md`, раздел 03). Перед отправкой проверь скриптом, что куски не перекрываются.
