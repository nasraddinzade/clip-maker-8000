# 05. Универсальный конвейер

Ниже разобрано, как устроен конвейер «Пяти колец» (около 4200 строк JS и Python), что из него переносится в любой ролик, а что относится только к стилю туши. Скрипты проверок, не привязанные к проекту, лежат в `../tools/` (см. `../tools/README.md`).

## 1. Схема

```
config/scenes.json ─┐            (тексты, подписи, тайминг-параметры, голос, музыка)
config/pronunciation.json ─┤     (ударения)
                    ▼
scripts/voice.mjs ── синтез по предложениям (кэш) → длины → config/timing.json
                    │                                   (длина сцены = 1,5 с + голос + 1,2 с,
                    │                                    начала фраз — якоря событий)
                    └─ сведение: голос −14 LUFS + музыка ровным слоем (фейды, без приглушения) → narration.wav
                    ▼
src/main.js ─ кадр n → сцена, t, камера → проходы рисования → подписи (экран) → пост
  │  window.__renderFrame(n)  — детерминированно, без часов
  │  window.__captionBoxes(n), __regions(n) — данные для проверок
  ▼
scripts/render.mjs ─ Vite (hmr off) + Puppeteer (WebGL на GPU) × 3 вкладки
  │  PNG по номеру кадра → build/frames → ffmpeg (H.264 yuv420p + AAC, длина = видео)
  │  режимы: --scenes, --from/--to, --reuse, --stills, --snap, --measure, --freeze
  ▼
проверки: кадры каждые N с, кропы 3×3, переходы по 8 кадров, движение, поля
подписей, вспышки, громкость, длины дорожек, стыки звука
```

## 2. Что переиспользуется как есть (любой стиль)

| Компонент | Файл в проекте | Суть | Для другого ролика |
|---|---|---|---|
| Конфиг сцен | `config/scenes.json` | тексты, подписи, `voiceDelay`, `tail`, `travel`, голос, музыка | меняются только тексты и модули сцен |
| Таймлайн от голоса | `scripts/voice.mjs`, `src/timeline.js` | длительности сцен = голос + запас; целое число кадров; начала фраз в `timing.json` | без изменений |
| Якоря событий | `ctx.phrase(n)`, `ctx.phraseEnd(n)`, `ctx.wordAt(n, "слово")` | событие привязано к фразе или слову | без изменений; `wordAt` оценивает время по доле букв, точнее дала бы разметка слов |
| Детерминированный кадр | `src/main.js` | `__renderFrame(n)`, время = n / fps, seed на сцену и элемент | обязательно в любом движке |
| Рендер | `scripts/render.mjs` | Puppeteer + Vite, несколько вкладок, PNG → ffmpeg, точечный перерендер | годится для любого браузерного рендера (canvas, WebGL, SVG, DOM) |
| Превью | `index.html` + `initPreview` | ползунок кадра, выбор сцены, Play со звуком, стрелки ← → | без изменений |
| Экранные подписи | `drawCaption` + `SAFE = 80` | подписи вне камеры, поле от края, ужатие длинной строки | поле подставить по площадке (`platforms.md`) |
| Камера | `src/scroll.js` | ключи `{s, x, y, z, lin}`, smootherstep, переезды, дыхание, параллакс с насыщением | полезно для любых «пролётов» по большому холсту |
| Голос по предложениям | `scripts/voice/silero.py` | файл на предложение, кэш по тексту с ударениями, таблица ударений | заменить движок, формат файла и кэш оставить. Исключение ElevenLabs v3: весь текст одним запросом, режь по тишине (`CLAUDE.md`, «Голос и звук») |
| Сведение звука | `scripts/voice.mjs` | два прохода `loudnorm`, музыка: зацикливание, ровный слой с эквалайзером и фейдами, проверка длины склейки | музыку по `CLAUDE.md` (без `sidechaincompress`, см. `lessons.md`, раздел «Музыка под голос»), остальное без изменений |
| Проверки | `../tools/*.py` | см. `../tools/README.md` | без изменений |

## 3. Что специфично для туши (не переносить вслепую)

- **Кисти и мазки** — `src/ink.js`: `makeInkStroke`, `liveStroke`, волоски, «фудэ» под 45°, нажим через √. Это решение ловушек p5.brush, а не общий приём. Сухой конец мазка без «гребёнки»: у каждой черты своё число волосков, у каждого волоска своя толщина, свой ритм разрывов и своя длина, не все дотягивают до конца черты. Равный шаг волосков поперёк кисти и общий ритм разрывов дают ровные зубья (`lessons.md`, «Версия v4»). Толщина волосков масштабируется с шириной мазка: волосок постоянной толщины 1 px у почти нулевой дуги складывается в чёрточку. Новый элемент рождается бледным и тонким, а не сразу толстым, иначе первый кадр даёт точку. Несколько лучей кляксы с перекрытием темнеют в клин (`lessons.md`, «Пять колец v14»).
- **Каллиграфия** — `src/calligraphy.js`: черты из KanjiVG (CC BY-SA 3.0), профиль нажима по типу черты, `strokeMotion`.
- **Печати** — `src/seal.js`: киноварь, непропечатка.
- **Шейдеры** — `src/gl/shaders.js`: бумага васи в мировых координатах, размывки по маске с нидзими по волокнам, туман-бумага, разрез бумагой, грануляция пигмента.
- **Свиток** — главы одна под другой, переезды через туман. Для «слайдовой» подачи замените на смену сцен.

## 4. Обязательные возможности рендерера (заложить до первой сцены)

1. **Кадр по номеру, без состояния между кадрами.** Если состояние нужно — пересчитывайте его от нуля или кэшируйте детерминированно.
2. **Seed на сцену и на каждый элемент.** Число отрисованных элементов не должно менять случайность последующих (`ctx.reseed(id)`).
3. **Режимы `--stills` (стоп-кадр главы), `--snap` (список кадров), `--from/--to`, `--reuse`.**
4. **Отладочные флаги страницы:**
   - `__noGrain` — без зерна;
   - `__fixCam` — неподвижная камера;
   - `__freeze` — заморозить содержимое, оставить дыхание камеры.
5. **Выгрузка данных для проверок:**
   - рамки подписей по кадрам (`__captionBoxes`);
   - рамки ключевых элементов с учётом камеры (`__regions`).
6. **Сервер рендера без HMR** и без слежения за файлами.
7. **UTF-8 вывод** во всех скриптах; пути с не-ASCII символами проверьте в первый же день.

## 5. Порядок проверок перед показом (минимум)

| Проверка | Инструмент | Критерий |
|---|---|---|
| Длины и формат | `audio_check.py lengths` | 1080×1920, 30 fps, видео = звук ± 1 кадр |
| Громкость | `audio_check.py loud` | −14 ± 1 LUFS, true peak ≤ −1 dBTP |
| Стыки звука | `audio_check.py joints` | на стыке тишина голоса; отрезки по 3 с прослушаны |
| Кадры каждые 2 с | `frames_every.py` | просмотрен лист; первый кадр не пустой |
| Кропы 3×3 | `crops3x3.py` | по кадру из середины каждой сцены; все 9 клеток просмотрены |
| Переходы | 8 кадров на переход | нет полос, обрывов, наложений на подпись |
| Поля подписей | `caption_margins.py` | 0 нарушений во всех кадрах |
| Вспышки | `flash_detector.py` | 0 вспышек; прогон на заведомо плохом входе показывает ≥1 |
| Движение | `motion.py` + глаза | участок «только дыхание» ≤ 1,5 с и событие хотя бы раз в 2 с по таблице событий, кроме задуманной паузы эссе из brief.md |
| Ударения | таблица из словаря | показана человеку, исправления внесены |

## 6. Цифры производительности (на этой машине)

AMD Radeon (встроенная), Ryzen 5 5600H, D3D11 через ANGLE:

- **Рендер:** около 7 кадров/с в 3 вкладки на кадр 1080×1920 с 5 GL-проходами и p5.brush. Полный ролик 82 с (2460 кадров) — около 6 мин.
- **Сборка mp4** (libx264, `-preset slow -crf 17`) — менее 1 мин.
- **Silero v4 на CPU** — секунды на предложение. Piper — доли секунды.
