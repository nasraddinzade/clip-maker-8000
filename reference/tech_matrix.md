# 06. Матрица выбора технологии под тип идеи

Матрица опирается только на изученное. Свой опыт «Пяти колец» — это p5.js 2.x, p5.brush, GLSL, Puppeteer и ffmpeg. Остальное прочитано по документации (`_research/video_motion.md`).

Пометки:
- **(опыт)** — проверено на практике;
- **(док.)** — прочитано, но не запускалось.

## Общее правило для всех типов
Выбирайте стек, в котором кадр — **чистая функция номера кадра** и который умеет стоп-кадр по номеру.

| Стек | Как получить кадр по номеру | Источник |
|---|---|---|
| p5 / Canvas / WebGL | свой `__renderFrame(n)` | (опыт) |
| Remotion | `useCurrentFrame()` | (док.) |
| GSAP | `timeline.seek()` | (док.) |
| Lottie | `goToAndStop(frame, true)` | (док.) |
| Manim | `-s`, `png-sequence` | (док.) |
| Blender | `-f` | (док.) |
| Motion Canvas | `/still` | (док.) |

Без этого не будет ни стоп-кадров для утверждения, ни параллельного рендера, ни честных проверок.

## Что переносится между всеми стеками (из нашего конвейера)
- Конфиг сцен и таймлайн от голоса.
- Голос по предложениям и якоря событий.
- Экранные подписи в безопасной зоне площадки.
- Проверки из `../tools/`: кадры каждые N с, кропы 3×3, вспышки, поля, звук.
- Независимое ревью свежим субагентом с номерами кадров (shotcraft).

## Чего не делать
- Не берите стек без покадрового рендера, например анимацию в реальном времени на Framer Motion из OneWave `animate`. Детерминизма и экспорта там нет.
- Не копируйте шейдерный код из The Book of Shaders («All rights reserved») и Shadertoy (по умолчанию, по вторичным данным, NC) в коммерческие ролики.
- Не тащите Remotion в рисованную генеративку. Холст p5.brush внутри React выигрыша не даёт (вывод исследования, не опыт).
