# Каркас рекламы «маскот плюс подборка»

Статус. Собран по ролику ai-helper-01 («Три дела ИИ-помощника», ramex.studio, 22.11.2026): 36,4 с, голос ElevenLabs v3, трек Mixkit «Okay» (103,34 BPM), −14,0 LUFS, true peak −1,5 dBTP. Человек принял v5 по виду («в целом окей»), v7 прошёл покадровый аудит (0 нарушений в 1092 кадрах). Свежий ревьюер на v5: креатив «нормальный», продаёт «нормальный, ближе к слабому», «угадай нейросеть» «частично»; его находки внесены в v6–v7, повторного ревью не было. Код: `templates/ad-mascot-list/`, промты: `prompts/ad/mascot-list_two_pass.md`. Проверен на одном ролике, второй ролик по каркасу должен подтвердить числа.

## Когда брать

Реклама услуги или продукта студии, который делает за владельца бизнеса несколько дел, и подача «вот N вещей, которые он делает» с ведущим-маскотом. Зритель владелец небольшого бизнеса, действие написать. Если продукт сайт, который принимает заказ, первым вариантом остаётся `reference/ad-template-site-order.md`. Структура подборки взята из `video-explainer-craft` (вариант «Подборка»: единый шаблон пункта, счётчик на экране), цель и приёмка из `video-ad-craft`.

## Что меняется от ролика к ролику

Только `config.json` шаблона, голос, трек, палитра (тема), логотип: тексты хука, шагов, экранов, наклеек, финала и карточки; какие экраны у шагов (переписка, заявка, пост); эмоции маскота по фразам; маскот из `src/mascot/` (новый проверяется рамкой всех поз). Вёрстка и переходы ниже не меняются без прогона проверок.

## 3. Движение и переходы

- Заголовок: слова из бледного (30 %) в тёмный по меткам голоса, ключевое слово красится чертой и наклоняется. В хуке первый заголовок тёмный с кадра 0.
- Экраны входят растворением со сдвигом до 60 px внутрь зоны и уходят растворением с уменьшением до 4 %. Выезд за край выводит текст из зоны (ai-helper-01, кадры 723–725).
- Переписка: у клиента «печатает» до сообщения, у помощника «печатает» 0,55 с до ответа; сообщения помощника цветом действия с белым текстом, клиента светлые (ревьюер не отличал, кто пишет). Старые сообщения гаснут до прокрутки, а не срезаются шапкой.
- Пост: картинка встаёт на слове о соцсетях, подпись печатается по буквам на «Готовит», кнопка после подписи. Точки «загрузки» не использовать: ревьюер счёл их признаком шаблона.
- Касание: кольцо без заливки сходится на кнопку, кнопка сжимается до 0,97 за 0,13 с, надпись меняется («Принять» → «Принято»), маскот звенит.
- Наклейки встают на ближайшую долю трека к своему слову. Наклейка шага держится до конца шага.
- Нет неподвижности дольше 0,7 с: маскот меняет эмоцию на последней фразе шага.
- Кривые только ease-out и ease-in-out (`reference/motion-craft.md`, раздел 11), линейное только постоянное (пар над чашкой).

## 4. Звук

- Голос одним запросом, проверка Whisper large-v3, паузы по огибающей (`video-voice`).
- Трек с ровной энергией, выбирает человек на слух; отрезок под ролик `mix.py` выбирает по наименьшему разбросу громкости, начало на доле.
- Музыка ровным слоем без автоприглушения, срез около 2,8 кГц на 4 дБ и мягкий срез низа около 500 Гц, мягкий компрессор 2:1, нарастание 1,5 с, затухание 3,5 с. Вариант A: медиана «музыка минус голос» в речи −22 дБ, B: −18 дБ, выбирает человек.
- Итог −14 LUFS, true peak −1,5 dBTP, длина ровно как у ролика.

## 5. Проверки (один раз, в конце)

`bash checks/run_checks.sh out/имя.mp4`: текст по DOM каждого кадра (запреты, зона, размер, срезанный край, маскот в кадре), контраст и перекрытие маскотом каждые 0,5 с, участки без подписи (не длиннее 1,5 с), длины, громкость, движение. Плюс лист кадров каждые 2 с глазами, обложка 1:1 и 3:4 в плитке 120 px, свежий ревьюер один раз (`video-qa`). Ловушки этих проверок в `reference/lessons.md`, «Ловушки проверок по DOM кадра».

## 6. Готовность

«Продаёт ли» не ниже «нормальный», нет признаков «заметит зритель» в «угадай нейросеть», все проверки шага 5 чистые, человек посмотрел на телефоне. Решение о публикации за человеком.

## 7. Что не доказано

- Тот же каркас с другим маскотом («Эр», «Пиши») не собирался.
- Подборка из 4–5 шагов не собиралась: веер и точки прогресса считают число шагов, вёрстку проверить.
- Аудиотеги v3 на русском: человек выбрал пробу с тегами на слух, отдельно их действие не доказано (`reference/tts.md`).
- Оценка ревьюера после правок v6–v7 неизвестна.
