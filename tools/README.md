# Инструменты проверки ролика

Переносимые скрипты, вынесенные из проекта «Пять колец». Зависимости: Python 3.10+, Pillow, ffmpeg и ffprobe в PATH. Другие пути к ffmpeg/ffprobe задаются переменными окружения `FFMPEG` и `FFPROBE`. Жёстких путей нет, все аргументы передаются в командной строке. Запускайте из этой папки: скрипты импортируют `_common.py`.

| Скрипт | Что проверяет | Пример |
|---|---|---|
| `frames_every.py` | кадры каждые N секунд и лист-сетка | `python frames_every.py out.mp4 --every 2 --out check/every2s` |
| `crops3x3.py` | кропы 3×3 в 100 % (мусор, края размывок, обрезанный текст) | `python crops3x3.py --video out.mp4 --at 12,40 --out check/crops` |
| `compare_sheet.py` | лист «было / стало» по версиям | `python compare_sheet.py --videos v1.mp4 v2.mp4 --at 2,10,25 --out cmp.png` |
| `motion.py` | участки, где картинка стоит (с оговорками) | `python motion.py --video out.mp4` или `--frames DIR --baseline DIR_FROZEN` |
| `caption_margins.py` | поля подписей и зоны интерфейса | `python caption_margins.py boxes.json --safe 80 --ui reels` |
| `flash_detector.py` | немонотонные растворения («вспышки») | `python flash_detector.py --frames DIR --box "kanji:250,600,830,1200" --range 2025:2094` |
| `audio_check.py` | громкость и пики, длины дорожек, стыки | `python audio_check.py loud out.mp4` · `lengths out.mp4` · `joints mix.wav --voice voice.wav --at 11.2,25.5` |
| `check_repo.py` | сам репозиторий правил, а не ролик: навыки и скрипты без записи в индексе, битые ссылки, маркеры слияния, повторные номера разделов, похожие на ключи строки | `python check_repo.py` |

Почти все скрипты при ошибке возвращают код 1, их можно ставить в конвейер. Исключения:
- `motion.py` только печатает отчёт;
- `frames_every.py`, `crops3x3.py` и `compare_sheet.py` готовят материал, который нужно смотреть глазами.

## Что рендерер должен уметь отдавать
Чтобы проверки работали без догадок, в рендере сразу заложите:
1. **Кадр по номеру.** Детерминированно, без часов и случайных чисел без seed.
2. **Рамки подписей по кадрам** в JSON. Без этого `caption_margins.py` не запустить.
3. **Рамки ключевых элементов по кадрам** с учётом камеры. Это иероглифы, логотипы, печати — всё, что появляется и исчезает. Они нужны `flash_detector.py --regions`.
4. **Режим без зерна и с неподвижной камерой**, чтобы мерить содержимое, а не шум и наезд.
5. **Режим «заморозить содержимое, оставить дыхание камеры»** — эталон для `motion.py --baseline`.

## Чего эти проверки НЕ доказывают
- `motion.py`: проходной замер не означает, что пауза живая. Медленный наезд и дрейф проходят порог, а глазом кадр стоит. Обязательно посмотрите видео.
- `crops3x3.py` ничего не проверяет сам, это материал для глаз. Смотрите все 9 клеток, а не одну «интересную».
- `audio_check.py joints` проверяет тишину голоса на стыке, а не качество фраз. Слушайте вырезанные отрезки.
- Ни один скрипт не проверяет ударения. Ударения проверяет человек на слух по таблице.
