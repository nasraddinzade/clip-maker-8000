# clip-maker-8000

Правила, навыки и проверки для коротких вертикальных роликов через Claude Code. Собраны на проекте «Пять колец» (Мусаси, тушь, p5.brush, 82 с), где ушло около десяти кругов правок. Цель в том, чтобы следующий ролик проходил за один-два круга.

## Как пользоваться

1. Скопируй содержимое этой папки в корень нового проекта ролика.
2. Отправь Claude Code промт из `prompts/00_start.md`.
3. Дальше иди по промтам `01` … `05`. На каждом шаге Claude Code останавливается и показывает результат.
4. Проверяй каждую остановку по `prompts/review_checklist.md`. Можно скинуть отчёт в чат Claude для ревью.

## Что внутри

| Путь | Что это |
|---|---|
| `CLAUDE.md` | общие правила, Claude Code читает их автоматически |
| `.claude/skills/video-style-dna` | культурный код темы, вопрос об аутентичности, шрифты и ассеты под культуру |
| `.claude/skills/video-brief` | вопросы до старта, бриф, сценарий |
| `.claude/skills/video-art-direction` | манифест стиля и стоп-кадры до анимации |
| `.claude/skills/video-voice` | синтез и свой голос, ударения, тайминг, сведение |
| `.claude/skills/video-qa` | обязательные проверки, ревью свежим взглядом, формат отчёта |
| `prompts/` | готовые промты для каждой остановки и типовых правок |
| `reference/` | уроки проекта, источники, TTS, площадки, конвейер, выбор стека, непроверенное |
| `tools/` | скрипты проверок на Python, описание в `tools/README.md` |

Ссылки на `_research/` и `tts_samples/` в `reference/` ведут в исходный плейбук проекта «Пять колец» (`D:\мусаси\out\playbook`). Там полные выписки с цитатами и 37 образцов голосов.

## Какую модель брать

- Opus для старта, стоп-кадров, анимации и полного ролика. Там вкус и много решений.
- Sonnet для голоса, точечных багов и скриптов.
- Haiku или Sonnet для экспорта.

## Что держать в голове

- Сначала стоп-кадры, потом анимация.
- Длина сцен считается от голоса.
- Отчёт без кропов и без раздела «НЕ прошло» не принимать.
- Лицензии голоса и музыки выяснять до работы. Silero некоммерческий.
- Данные о площадках устаревают. Раз в 3–6 месяцев перепроверяй `reference/platforms.md`, сомнительное перечислено в `reference/unverified.md`.

## Обновление

После каждого ролика попроси Claude Code дописать новые уроки в `reference/lessons.md`, а правило, которое сработало бы раньше, добавить в `CLAUDE.md` или в нужный навык.
