# clip-maker-8000

Правила, навыки, промты и проверки для коротких вертикальных роликов через Claude Code. Собраны на трёх проектах: «Пять колец» (эссе про Мусаси, тушь, p5.brush), два ролика-рекламы про витрину магазина (оба признаны слабыми, из них выросли правила красоты) и разбор 12 реальных рекламных роликов про сайты и приложения. Цель в том, чтобы следующий ролик проходил за один-два круга.

Репозиторий учится на опыте. Claude Code, который делает ролик по этим правилам, предлагает в отчёте уроки (ошибки, которые правило поймало бы раньше, сработавшие приёмы, замечания человека), а человек и чат проекта решают, что записать (`CLAUDE.md`, «Репозиторий учится на роликах»).

## Как пользоваться за минуту

1. Открой Claude Code в этой папке или скопируй её содержимое в корень своего рабочего каталога (CLAUDE.md, `.claude/`, `prompts/`, `reference/`, `tools/`). Проекты роликов Claude Code создаёт в `projects/<имя>/`, эта папка в git не попадает.
2. Скажи Claude Code по-человечески, какой ролик нужен. Например: «сделай рекламный ролик про наш сайт» или «сделай образовательный ролик про то, как работает X». Навык `video-router` определит тип и поведёт по нужному маршруту.
3. На каждой остановке Claude Code показывает результат и ждёт «да». Проверяй по `prompts/review_checklist.md`.

Хочешь стартовать вручную, возьми готовый промт типа из таблицы.

### Если проект ролика лежит в своей папке

Копия правил внутри проекта устаревает, пока репозиторий пополняется из других чатов. На «Пяти кольцах» Claude Code в папке проекта не нашёл `reference/motion-craft.md`, потому что правила туда скопировали раньше. Делай так.

1. Держи один клон репозитория рядом с проектами, например `D:\clip-maker-8000`, и не копируй из него файлы по одному.
2. В `CLAUDE.md` проекта первой строкой поставь импорт `@D:/clip-maker-8000/CLAUDE.md`. Claude Code подгрузит общие правила, а пути вида `reference/…` ищи в клоне.
3. Перед каждой остановкой `git -C D:\clip-maker-8000 pull`. Навыки из клона копируй в `.claude/skills` проекта после каждого обновления, старые копии навыков удаляй.

## Какой ролик, какой маршрут

| Что просишь | Тип | Навык | Первый промт | Носитель по умолчанию |
|---|---|---|---|---|
| реклама сайта, приложения, услуги, товара; показ работ студии | **реклама** | `video-ad-craft` | `prompts/ad/00_start.md` | анимация из настоящих скриншотов в коде (Remotion), несколько устройств, среда со светом |
| образовательный, обучающий, информационный, новостной, подборка, данные | **объяснялка** | `video-explainer-craft` | `prompts/explainer/00_start.md` | схемы, счётчики, графики и типографика в коде, голос, источники на экране |
| авторский ролик про идею, философию, историю, культуру | **эссе** | `video-essay-craft` | `prompts/essay/00_start.md` | стиль эпохи (например, тушь на p5.brush), голос, образы-метафоры |

Остановки по типам:
- реклама: бриф → концепт → трек → взгляд → аниматик без звука → сведение и экспорт;
- объяснялка: бриф → сценарий и источники → стоп-кадры → сцена в движении → голос → полный ролик → экспорт;
- эссе: бриф и сценарий → стоп-кадры → сцена в движении → голос → полный ролик → экспорт.

Статус типов: эссе пройдено на практике, реклама в работе (два провала, третий ролик в сборке), объяснялка пока по документации и общим практикам. Первый проект типа дописывает уроки.

## Какую модель брать

- Opus для старта, концептов, взгляда, анимации и полного ролика. Там вкус и много решений.
- Sonnet для голоса, подбора трека, точечных багов и скриптов.
- Haiku или Sonnet для экспорта.

## Что держать в голове

- Сначала тип, потом всё остальное.
- Сначала стоп-кадры или взгляд, потом анимация.
- Проверки ловят дефекты, а не красоту. «Слабый, нормальный, сильный» ставит свежий субагент и человек, не сборщик.
- Отчёт без кропов и без раздела «НЕ прошло» не принимать.
- Лицензии голоса и музыки выяснять до работы.
- Данные о площадках устаревают. Раз в 3–6 месяцев перепроверяй `reference/platforms.md`, сомнительное перечислено в `reference/unverified.md`.
- Репозиторий публичный: не клади сюда реальные данные клиентов, чужие бренды, контракты, личные пути и чужие видео.

## Обновление

После каждого ролика попроси Claude Code дописать уроки в `reference/lessons.md`, а правило, которое сработало бы раньше, добавить в `CLAUDE.md` или в нужный навык. Как раскладывать новое по файлам и не ломать написанное из других чатов, описано в `CONTRIBUTING.md`. Перед каждым коммитом в репозиторий запускай `python tools/check_repo.py`. Через 48 часов после публикации добавь цифры из Insights.
