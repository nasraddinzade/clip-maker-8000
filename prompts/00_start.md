# Старт. Какой это ролик

Скажи Claude Code по-человечески, например «сделай рекламный ролик про наш сайт» или «сделай образовательный ролик про X». Навык `video-router` сам определит тип. Если хочешь стартовать вручную, возьми промт типа.

| Что нужно | Тип | Навык | Первый промт | Модель |
|---|---|---|---|---|
| реклама сайта, приложения, услуги, товара; показ работ студии | реклама | `video-ad-craft` | `prompts/ad/00_start.md` | Opus |
| образовательный, обучающий, информационный, новостной, подборка, данные | объяснялка | `video-explainer-craft` | `prompts/explainer/00_start.md` | Opus |
| авторский ролик про идею, философию, историю, культуру | эссе | `video-essay-craft` | `prompts/essay/00_start.md` | Opus |

## Все промты по типам

| Тип | Остановки и промты |
|---|---|
| реклама | `ad/00_start` (бриф, концепты) → `ad/01_track` → `ad/02_look` (взгляд) → `ad/03_animatic` → `ad/04_final_export` |
| объяснялка | `explainer/00_start` (бриф, сценарий, источники) → `01_stills` → `02_one_scene` → `03_voice` → `04_full` → `05_export` |
| эссе | `essay/00_start` (бриф, сценарий) → `01_stills` → `02_one_scene` → `03_voice` → `04_full` → `05_export` |

Для всех типов: проверка остановок по `review_checklist.md`.

## Какую модель брать

- Opus для старта, концептов, взгляда, анимации и полного ролика. Там вкус и много решений.
- Sonnet для голоса, подбора трека, точечных багов и скриптов.
- Haiku или Sonnet для экспорта.
