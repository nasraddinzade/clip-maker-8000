# Объяснялка. Промт 3. Голос

Голос общий для всех типов с дикторским текстом. Используй `prompts/essay/03_voice.md` без изменений, плюс:

```
Особенность объяснялки. Ударения проверь для всех терминов, имён, названий и чисел словами. Хвост сцены около 0,4–0,6 с, вступление около 0,3 с, итоговый темп утверждаю я по таблице длин. Если длина выше потолка, предложи сокращения текста с выигрышем в секундах и не режь факты, у которых есть источник, без моего согласия.
```
