# Объяснялка. Промт 0. Старт, бриф, сценарий и источники (модель Opus)

Тип «объяснялка»: образовательный, обучающий, информационный, новостной ролик, подборка, история данных (`video-explainer-craft`). Другие типы, `prompts/00_start.md`.

```
Новый ролик. Работай по навыку video-explainer-craft и CLAUDE.md.
Тема [ТЕМА]. Вариант [объясняющий / обучающий / новостной / подборка / история данных, или удали, тогда определи сам и скажи какой].
Площадка [Reels / Shorts / TikTok]. Длина около [N] с, потолок [M] с.
Что зритель должен вынести [ОДНО ПРЕДЛОЖЕНИЕ].
Стиль [референсы или удали, тогда определи по video-style-dna]. Голос [мой / синтез / без голоса].

1. Проверь текущую дату инструментом и запиши её в brief.md.
2. video-style-dna, потом video-brief. Запиши brief.md.
3. Найди источники по теме. Для новостей минимум два независимых, для остального первичные. Веди facts.md: утверждение, источник, дата проверки.
4. Предложи текст диктора и таблицу «фраза → кадр → источник». Хук из reference/hooks.md.
ОСТАНОВИСЬ. Код не пиши. Я проверяю факты и длину.
```

## Если факты не сошлись

```
В сценарии есть утверждение без надёжного источника [какое]. Убери его или найди первичный источник, не смягчай формулировкой. Покажи обновлённую таблицу.
ОСТАНОВИСЬ.
```
