# Промт 4. Полный ролик (модель Opus)

```
Голос утверждён. Собери все сцены по таймлайну от голоса, сведи звук (−14 LUFS, музыка [путь и лицензия / без музыки]).
Прогони все проверки из навыка video-qa, включая подписи по безопасной зоне [площадка]. Потом запусти субагента свежим взглядом на листы и кропы.
Покажи путь к mp4, кадры каждые 2 с, листы переходов, результаты всех проверок, находки субагента, лист «было / стало» с прошлой версией. Отчёт по формату video-qa.
ОСТАНОВИСЬ.
```

## Точечный баг

```
Баг на [ВРЕМЯ] с. [ЧТО ВИДНО].
Вытащи все кадры участка, измерь проблему числами, найди причину и покажи её на кадрах. Не гадай. Исправь причину, а не симптом. Напиши или дополни автопроверку этого класса ошибок и прогони её по всему ролику, сначала на старых кадрах (должна найти), потом на новых. Перерендери только затронутый участок, проверь длины дорожек.
ОСТАНОВИСЬ. Покажи причину, кадры до и после, результат проверки.
```
(Точечный баг можно отправлять на Sonnet.)
