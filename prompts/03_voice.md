# Промт 3. Голос (модель Sonnet)

## Синтез

```
Переходим к голосу по навыку video-voice. Ролик [коммерческий / нет].
Сделай 2–3 пробы разных движков на тексте сцены [N]. Лицензию каждого проверь по LICENSE.
Потом выбранным движком синтезируй все предложения отдельными файлами, словарь ударений для всех многосложных слов и таблицу «сцена → предложение → слова с ударением». Докажи ударения самым сильным доступным способом и напиши каким.
Пересчитай длины сцен от голоса и покажи итоговую длину ролика. Если выше потолка, предложи сокращения текста с выигрышем в секундах.
ОСТАНОВИСЬ.
```

## Свой голос

```
Озвучку запишу сам. По навыку video-voice подготовь record/script.md (фразы, целевые длительности, ударения, паузы, памятка по записи на телефон) и скрипт приёма записей из папки voice_own/ любого формата. Обработка живая, без эффектов, исходники не трогать. Покажи таблицу длин «было / стало» и какие сцены надо перерендерить. Сам не перерендеривай.
ОСТАНОВИСЬ.
```
