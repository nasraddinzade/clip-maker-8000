# Промт 0. Старт эссе (модель Opus)

Тип «эссе»: авторский ролик с голосом про идею, историю, культуру (`video-essay-craft`). Другие типы, `prompts/00_start.md`.

Работай в `projects/<имя>/` внутри клона репозитория (CLAUDE.md, раздел «Шаг 0»). Если проект живёт в отдельной папке с копией правил, перед каждым кругом обнови копию из `git pull`, иначе новые правила до проекта не дойдут. Потом отправь это, заменив скобки.

```
Новый ролик. Тема [ТЕМА]. Площадка [Reels / Shorts / TikTok], аккаунт [личный / бизнес], монетизация [да / нет].
Длина около [N] с, потолок [M] с.
Что зритель должен вынести [ОДНО ПРЕДЛОЖЕНИЕ].
Стиль [2–3 референса или описание]. Чего не надо [СПИСОК].
Аутентичность культуры темы [0 нейтрально / 1 намёки / 2 стилизация / 3 аутентично, или удали строку, тогда Claude спросит сам].
Голос [мой / синтез / без голоса]. Музыка [есть трек и лицензия / нужна бесплатная / без музыки].

Работай строго по CLAUDE.md и навыку video-essay-craft. Начни с video-style-dna, потом video-brief. Веди интервью выбором по reference/interview.md (карточки с вариантами через AskUserQuestion, пересказ идеи и «Верно понял?»), запиши brief.md, выбери стек по reference/tech_matrix.md, предложи сценарий по сценам в формате «фраза → образ → почему метафора».
ОСТАНОВИСЬ после сценария. Код не пиши.
Репозиторий учится на этом ролике: в конце каждого отчёта раздел «Предлагаю в репозиторий» (урок, доказательство, какое правило и где, тип ролика). Правило не подходит ролику, скажи, а не выполняй вслепую. Сам в репозиторий не пиши.
```
