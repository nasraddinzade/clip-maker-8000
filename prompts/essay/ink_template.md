# Промт. Эссе по каркасу «тушь на бумаге» (модель Opus)

Для эссе в стиле туши, кисти и бумаги: Япония, Китай, дзен, восточная философия. Каркас `reference/essay-template-ink.md`, два прохода вместо пяти остановок. Другой стиль, `prompts/essay/00_start.md`.

## Проход 1

```
Новое эссе по каркасу reference/essay-template-ink.md. Сначала git pull в клоне clip-maker-8000, работай в projects/<имя>/.
Тема [ТЕМА]. Текст голоса [ВСТАВЬ ИЛИ «напиши сам, около N с»]. Главы [N, понятия и знаки, или «предложи»].
Площадка [Reels / Shorts / TikTok], аккаунт [личный / бизнес], ролик коммерческий [да / нет].
Логотип [путь к файлу или «без логотипа»], края букв состаривать [можно / нельзя].
Музыка [есть трек и лицензия / найди 2–3 бесплатных с лицензией на все площадки].

Работай по CLAUDE.md, video-essay-craft и каркасу. Числа и решения каркаса уже приняты, не пересматривай их без причины, а если правило мешает этому ролику, напиши это в отчёте.
Сделай весь проход 1 из раздела 7 каркаса. Интервью выбором только по тому, чего нет выше. Если на этой машине есть проект «Пять колец», возьми его рендерер как основу по разделу 6.
Покажи одной остановкой: сценарий с таблицей событий, голос (файл целиком с таймкодами и таблица ударений), кандидаты музыки, style.md, стоп-кадры всех сцен в 100 % и 360 px, лист-сетку, полосы 0,2 с для событий, самопроверку стоп-кадров, «Решения по сценам» в brief.md.
ОСТАНОВИСЬ. Полный ролик не рендери. В конце раздел «Предлагаю в репозиторий».
```

## Проход 2

```
Утверждаю проход 1 с правками: [СПИСОК ИЛИ «без правок»]. Решения впиши в brief.md с меткой [РЕШЕНИЕ БРИФА].
Сделай проход 2 по разделу 7 каркаса: полный рендер, сведение, все проверки из раздела 8, обложка, петля. Свежий ревьюер обязателен, с брифом и метками, новое отдельно от старого, худший участок метрик, сравнение с прошлой версией.
У каждой правки правило и источник. ОСТАНОВИСЬ. Отчёт по формату video-qa, отдельной строкой что смотреть человеку на телефоне, в конце «Предлагаю в репозиторий».
```

## Правки и экспорт

Один список правок после просмотра на телефоне, затем `prompts/essay/05_export.md`.
