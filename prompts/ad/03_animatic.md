# Реклама. Промт 3. Аниматик без звука (модель Opus)

```
Взгляд принят [с правками: ...]. Собери полный ролик без звука и без финальной карточки.
Ритм по долям выбранного трека [путь]. Хук, главы по 2–4 с, подписи в безопасной зоне Reels (reference/platforms.md).
Проверки по video-ad-craft, раздел «Приёмка»:
- нет фрагментов короче 1,2 с без читаемого смысла;
- в коде нет линейных кривых (grep);
- нет неподвижных кадров дольше 0,7 с;
- распознавание текста по всем кадрам на запрещённые слова [бренды, «оплата», службы доставки];
- ключевые надписи и кнопки по пикселям в полосе 14–65 % высоты и в 6 % от боков;
- каждый экран показан в 100 % кропе в ключевой момент.
Каждую проверку сначала прогони на заведомо плохом кадре и покажи, что она срабатывает.
Покажи mp4, полосу кадров 10 в секунду, таблицу событий и находки. Запусти свежего субагента без твоих «исправлено» с просьбой поставить «слабый, нормальный, сильный» с причинами по хуку, ритму, тексту, устройствам и финалу. Отчёт по формату video-qa.
ОСТАНОВИСЬ.
```

## Если ритм или хук не нравятся

```
Не принято: [ЧТО ВИДИШЬ, секунды]. Не ускоряй файл. Правь времена событий и крупности, привяжи события к долям. Покажи «было / стало» по кадрам и новую таблицу событий.
ОСТАНОВИСЬ.
```
