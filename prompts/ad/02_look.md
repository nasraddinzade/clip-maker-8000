# Реклама. Промт 2. Взгляд (модель Opus)

Самая важная остановка. На ней решается, будет ролик красивым или нет. Не принимай, пока не посмотрел сам.

```
Концепт и трек выбраны [названия]. Делай остановку «Взгляд» по навыку video-ad-craft.
Инструмент [Remotion, официальные пакеты, лицензию проверь и напиши]. Захват настоящих экранов по reference/devices.md: каждое устройство своим размером окна, масштаб не ниже 3, состояния по настоящим касаниям.
Покажи в финальном качестве:
1. Хук (два варианта первой секунды).
2. Общий план «все экраны» [если устройств больше одного].
3. По одному кадру на каждое устройство в ключевой момент.
4. Результат.
5. Карточка контакта [только подтверждённые данные].
Плюс тест движения 5–6 с без звука: переход между устройствами и макро-наезд, полоса кадров 5 в секунду.
Цели красоты: reference/reel-references.md. Среда со светом и тенью, непрерывная камера, макро на ключевом действии, подписи 2–6 слов в безопасной зоне.
Сам назови слабые места. Если кадр выглядит как скриншот в рамке, скажи об этом и переделай. Оценку «слабый, нормальный, сильный» не ставь, её ставит свежий субагент.
ОСТАНОВИСЬ.
```

## Если выглядит плоско

```
Взгляд не принят: [ЧТО ВИДИШЬ, по кадрам]. Не добавляй равномерный блик и градиентные пятна. Посмотри в reference/reel-references.md, чего не хватает: среда со светом, параллакс фона, макро, глубина подписи. Предложи конкретные изменения по кадрам, покажи «было / стало» (tools/compare_sheet.py) и тест движения.
ОСТАНОВИСЬ.
```
