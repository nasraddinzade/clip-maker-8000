# Реклама. Промт 4. Сведение, финал, приёмка (модель Opus), экспорт (Sonnet или Haiku)

## Сведение и финал (Opus)

```
Аниматик принят [с правками]. Добавь выбранный трек ровным слоем без автоприглушения, уровень [человек выбрал на слух из двух вариантов]. Громкость −14 LUFS, true peak не выше −1 dBTP. Карточка контакта 2,5–3 с, предыдущий экран гаснет полностью до её появления.
Прогони все проверки video-qa и приёмку video-ad-craft. Свежий субагент ставит «Креативная оценка» по полосе кадров 10 в секунду. Всё, что требует ушей, отдельной строкой для меня.
Покажи mp4, отчёт по формату video-qa, находки субагента.
ОСТАНОВИСЬ.
```

## Экспорт (Sonnet или Haiku)

```
Ролик утверждён. Сделай экспорт под [Reels / Shorts / TikTok].
1. Мастер 1080×1920, 30 fps CFR, H.264 High, yuv420p, AAC-LC 48 кГц 192 кбит/с, +faststart.
2. Лёгкая версия до 100 МБ для мессенджеров.
3. Положи рядом LICENSES.md: лицензия музыки (скриншот условий), шрифтов, инструмента.
Проверь длины дорожек, громкость, безопасную зону. Путь и размеры файлов покажи.
ОСТАНОВИСЬ.
```

## Перед публикацией (делаешь сам)

- Загрузи черновик в приложение и посмотри, что закрывает интерфейс.
- Посмотри ролик на телефоне со звуком и без.
- Для YouTube загрузи сначала приватно и проверь Content ID.
