# Промт 2. Одна-две сцены в движении (модель Opus)

```
Стоп-кадры утверждены. Анимируй сцены [N и N+1] с переходом между ними. Голоса пока нет, тайминг временный.
Для каждой сцены составь таблицу событий «событие → якорь (фраза или слово) → время». Событие хотя бы раз в 1,5–2 с, дрейф событием не считается. Все исчезновения монотонные.
Покажи mp4 без звука, кадры каждые 2 с, 8 кадров перехода, таблицу событий, замер движения и детектор вспышек. Отчёт по формату video-qa.
ОСТАНОВИСЬ.
```

## Если медленно или скучно

```
Темп вялый в [ГДЕ, секунды]. Не ускоряй файл и не добавляй дрейф камеры. Сократи ожидание внутри сцены, ускорь отрисовку ключевых элементов и добавь событие с якорем на фразу в каждую паузу длиннее 2 с.
Покажи таблицу событий «было / стало» и кадры каждые 2 с.
ОСТАНОВИСЬ.
```
